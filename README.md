# 영단어 플래시카드 웹앱

205개 영단어 플래시카드와 영어↔한글 4지선다 테스트가 들어 있습니다.

## iPhone·iPad에서 앱처럼 쓰기

1. 이 폴더의 파일을 무료 정적 호스팅 서비스에 올립니다. GitHub Pages를 사용하면 됩니다.
2. 생성된 주소를 iPhone 또는 iPad의 Safari에서 엽니다.
3. 공유 버튼을 누른 뒤 **홈 화면에 추가**를 선택합니다.

홈 화면 아이콘으로 실행하면 일반 앱처럼 열립니다. 처음 한 번 온라인으로 열면 이후에는 오프라인에서도 사용할 수 있습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 폴더 안의 파일과 `icons` 폴더를 모두 저장소의 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. 표시되는 사이트 주소를 Safari에서 엽니다.

점수는 각 기기에 따로 저장됩니다.
